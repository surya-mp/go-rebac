# Security policy

Report suspected authorization bypasses, tenant-isolation failures, tuple/model
validation gaps, or supply-chain concerns privately to the repository owner.
Do not open a public issue until a maintainer confirms a fix or coordinated
disclosure plan.

Supported releases are the latest published v0 minor release and the upcoming
main branch. Releases are built only from version tags after CI, include an
SPDX SBOM, and carry a keyless Sigstore bundle for the SBOM.
